# WathiqPay website

Public-facing website for the proprietary WathiqPay project. The product is not open source; the website must not advertise public source-code access or link visitors to internal repository documents.

## Development

Run `npm ci`, then `npm run dev` from this directory. Run `npm run build` to generate `dist/`. The landing page is implemented in `src/Landing.jsx`, with styles in `src/site.css`.
